- 記録日: 2026-10-29（最終更新: 2026-10-30）

## 1. 背景

現行名は「積読（つんどく）」の語呂。ただし積読という語は既に複数のアプリで使われており、
検索でも区別がつかない。

| 実測（2026-10-29） | 内容 |
|---|---|
| Google Play | `Tsundoku - 積読 -` が存在 |
| App Store | `私は積読家 - 積読管理と読書記録` が存在 |
| Web | 「積読」は読書論・書評メディアの一般語として定着済み |

改名の目的は 2 つ。

1. **ググラビリティ**: 名前で検索したときに競合アプリが出ないこと
2. **情緒**: 「買ったのに読んでいない本」を肯定するニュアンスを持たせること

## 2. 判定基準

| 軸 | 定義 |
|---|---|
| 競合アプリ衝突 | 同名または近名のアプリ・サービスが存在しないか |
| トークン性 | 検索エンジンが固有名詞として扱うか（一般語に吸収されないか） |
| 入力性 | IME・キーボードで再現できるか |
| 口頭性 | 読みを聞いて一意に辿れるか（同音語が少ないか） |
| SERP 占有 | 検索結果1ページ目を誰が持っているか |

### 判定基準の修正

当初は「SERP を占有できるか」で採点していたが、個人開発アプリの発見経路は
X・GitHub・技術系イベント・ブログが主で、Google の順位ではない。
そのため合格ラインを **「検索して競合アプリが出ないこと」** に緩和した。
辞書ページや同名の書籍が出ることは失格条件にしない。

### 実測方法と限界

- Web 検索（2026-10-29 時点）。一部は検索バックエンドのフォールバックを経由しており、
  結果は**方向性の参考**であって網羅的な調査ではない
- ストア検索・商標（J-PlatPat / USPTO）・ドメイン WHOIS は未実施

### 3.5 genizah

- 意味: ユダヤ教で、古くなった聖典を捨てずに保管する倉
- ヘブライ語: **גניזה**
- 実測: 競合アプリはゼロ。ただし SERP は学術・宗教（Dicta Genizah Search、
  Friedberg Genizah Project、Princeton Geniza Lab など）が占有
- 同名プロジェクト: [geniza.cz](https://geniza.cz/en/homepage)

**語源の裏付け**: エズラ記のアラム語に次の一節がある。

> בְּבֵית סִפְרַיָּא דִּי גִנְזַיָּא מְהַחֲתִין תַּמָּה
> 「書物の家、すなわちゲニザに納められている所」

בית גנזיא（ベイト・グナズヤ）は、王の文書と財宝を保管する機関を指す。
つまり **genizah は元々「聖典専用の箱」ではなく、文書と財宝の保管庫**であり、
本アプリの用途に対して語源的に正当な借用である。

## 4. 決定

```
   גניזה
  genizav
すてない本棚
```

### 4.1 由来

`genizah`（保管庫）＋ `v`。`v` は次のどちらにも読める。

| v | 意味 |
|---|---|
| viewer | 本アプリはビューアー |
| vault | 鍵付き保管庫（暗号化して保存する実態） |

### 4.2 表記ルール

| 場面 | 表記 |
|---|---|
| ロゴ・リポジトリ・ドメイン | `genizav`（すべて小文字） |
| 日本語表記 | ゲニザヴ |
| 読み | ゲニザブ（Pixiv → ピクシブ と同じズレ方） |
| ストア名 | `genizav - すてない本棚` |
| 検索語の設計 | `genizav 本棚` / `ゲニザヴ アプリ` |
| About | ヘブライ語 גניזה（保管庫）＋ viewer と明記 |

### 4.3 ヘブライ語の扱い

- ロゴには **גניזה（原型）** を小さく添える。改変しない
- **גניזב は使わない**。理由:
  - `"גניזב"` で検索すると「הלכות גניבה（窃盗の法）」のページが返る（גנ״ב の連想）
  - ヘブライ語話者には גניזה の綴り間違いに見える
  - RTL・ヘブライフォント・bidi の実装コストが増える

## 7. Ligrol のカタカナ衝突調査（2026-10-30）

### 7.1 結論

`リグロル` は「既存ブランドと同名」ではない。代わりに **検索エンジンが `リグロス` に自動矯正する**。
`リグロス` はホロライブ ReGLOSS・科研製薬の歯周組織再生剤・REGLOS の企業群で埋まっており、
カタカナ単独では本アプリに到達できない。昨日の「検索が完全に空き」は Latin 表記 `ligrol` の話で、
カタカナは未検証だった（§2 の実測限界どおり）。

### 7.2 検索（2026-10-30 / Google JP・Yahoo! JAPAN）

| クエリ | 実測 | 判定 |
|---|---|---|
| `リグロル` | Google「次の検索結果を表示しています: リグロス」/ Yahoo「リグロスで検索しています」 | 🔴 吸収 |
| `"リグロル"`（引用符） | Google でも `"リグロス"` に矯正 | 🔴 矯正は引用符を貫通 |
| `リグロル` 完全一致（Yahoo `qrw=0`） | 約6件。大半が AlphaPolis / カクヨム『姫様になんてならないから！』の登場人物名 | △ ブランドではなく小説の人物名 |
| `リグロール` | 矯正なし。GARDNER リグロール（カー用品ケース）、YouTube チャンネル `リグロール`、`Re リグロール シャルドネ トリートメント`（フリマ/EC） | 🟡 同名商品あり |
| `リグロ` | Google サジェストが `リグロス` / `リグロEX5` / `リグロス歯科` / `ReGLOSS` を返す | 🔴 ロート製薬 REGRO の領域 |

補足:

- Google の `リグロル 本棚` は矯正されないが、`リグロル` は無視されて本棚家具の結果になる（`もしかして: リグロス 本棚`）。
- `リグロル 読書アプリ` は `リグロス 読書アプリ` に矯正される。
- `リグロール アプリ` は矯正されないが、`ログロール`（人材派遣）と `ロジクール` が混入する。

### 7.5 推奨

1. **Latin `Ligrol` を主検索トークンにする**。ストア名も `Ligrol - 積読本棚` のように Latin 先頭。`リグロル` は読み・説明用に残す。
2. カタカナ検索も取りたいなら **`リグロール` に変更**。自動矯正は消えるが、`Re リグロール`（ヘアケア）と `GARDNER リグロール`（カー用品）が既存。
3. どちらも許容できないなら、`リグロ*` を避けて再命名する。`リグロ` はロート製薬、`リグロス` は科研製薬＋ReGLOSS が占有している。

> 法的判断ではない。商標の最終確認は J-PlatPat の称呼検索と、必要なら弁理士レビューで行う。
