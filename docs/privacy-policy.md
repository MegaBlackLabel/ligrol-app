# プライバシーポリシー

Ligrol（以下「本アプリ」）における、利用者の情報の取り扱いを定めます。

- 最終更新: 2026-11-09
- 対象: 本アプリのデスクトップ版（Windows / macOS）

## 1. 基本方針

- 本アプリは**アカウント登録を必要としません**。取り込んだ本の閲覧はオフラインで完結します。
- 購入履歴・本のファイル・表紙・タグ・読書進捗・付箋・閲覧履歴・設定は、**お使いの PC の中**に保存されます。
- Google Drive へのバックアップは**任意**です。有効にした場合だけ、後述のデータが Google Drive に保存されます。
- アクセス解析・広告・利用状況の送信・クラッシュレポートの送信は行いません。

## 2. 端末内に保存する情報

| 情報 | 内容 |
|---|---|
| 本のデータ | ストアから取り込んだ本（アプリ独自形式 `.nartik`。アカウントごとの鍵で暗号化） |
| 本棚の情報 | 購入履歴のメタデータ、タグ、表紙・サムネイル、お気に入り、読書進捗、付箋、閲覧履歴、設定 |
| ログイン状態 | 各ストアのセッション Cookie（後述）と、Google の認証トークン（後述） |
| ログ | 動作ログ（`logs/ligrol.log`）。アカウント識別子（`sub`）などの復号材料は書きません |

保存先は OS ごとに次の場所です（設定画面から変更できます）。

| OS | 場所 |
|---|---|
| Windows | `%APPDATA%\ligrol\` |
| macOS | `~/Library/Application Support/ligrol/` |

## 3. ストアのログイン状態

技術書典 / BOOTH / FANZA同人 / DLsite / Fantia のセッション Cookie は、**OS の資格情報ストア**
（Windows: 資格情報マネージャー / macOS: キーチェーン）にある専用の鍵で**暗号化して**保存します。
**保存期間は 7 日**で、過ぎたセッションは起動時に破棄して再ログインを求めます（期限は暗号文の中に
入っているため、データベースを書き換えても延ばせません）。「ログアウト」でいつでも削除できます。

## 4. Google アカウントとの連携

Google ログインは、**Google Drive へのバックアップ**と**本の取り込み**に使います。ログインは任意で、
すでに取り込んだ本を読むのにログインは要りません。

### 4.1 取得する情報

| 情報 | 用途 |
|---|---|
| アカウント識別子（`sub`） | 本の所有者の判定、本の鍵の復元 |
| メールアドレス・表示名・プロフィール画像の URL | アプリ内のアカウント表示 |
| アクセストークン・リフレッシュトークン | Google Drive へのアクセス（OS の資格情報ストアに暗号化して保存） |

### 4.2 要求するスコープ

- `openid` / `email` — アカウントの識別と表示
- `https://www.googleapis.com/auth/drive.file` — 本アプリが作成したファイル、または利用者が選択したファイルだけ

`drive.file` 以外の Drive 全体へのアクセス権（`drive` / `drive.readonly`）は要求しません。

### 4.3 Google から取得したデータの扱い

- 取得したデータは、本アプリの機能（バックアップ・復元・本の取り込み）の提供にのみ使います。
- **第三者への提供・販売、広告への利用、AI モデルの学習への利用は行いません。**
- Google API Services User Data Policy（Limited Use 要件を含む）を遵守します。

### 4.4 Google Drive に保存される内容

Google Drive の `ligrol/` フォルダに、次のファイルを保存します（バックアップを有効にした場合のみ）。

| ファイル | 内容 |
|---|---|
| 本のファイル（`.nartik`） | 取り込んだ本（設定で「書籍のバックアップ」を OFF にすると送信しません） |
| `ligrol-backup.json` | 本棚のデータ（お気に入り・付箋・履歴など）。本の本文や画像は含みません |
| `ligrol-thumbs.json` | 表紙のサムネイル |
| `ligrol-keys.json` | 本の鍵を「Google アカウントで解ける形」と「パスフレーズで解ける形」でラップしたもの |

本のファイルは本の鍵で暗号化され、それ以外のバックアップファイルも暗号化された形（封筒）で
保存されます。Google Drive 上のファイルは、Google の利用規約およびプライバシーポリシーにも
従います。

## 5. 本の暗号化と鍵

取り込んだ本は、アカウントごとに作られる乱数の鍵で暗号化されます。鍵は OS の資格情報ストアと、
Google Drive の `ligrol-keys.json` に保存されます（バックアップを使う場合）。パスフレーズを設定すると
Google に依存しない復元手段を持てますが、設定の「パスフレーズ必須」を ON にしない限り、Drive の
バックアップとアカウント識別子の両方を取得された相手は鍵を解けます。詳細と限界は README の
「本の鍵（暗号化と復元）」を参照してください。

## 6. 外部との通信

本アプリが通信するのは、次の場合だけです。

| 送信先 | 目的 |
|---|---|
| 各ストア（技術書典 / BOOTH / FANZA同人 / DLsite / Fantia）と表紙画像の配信元 | ログイン、購入一覧の同期、本のダウンロード、表紙の取得 |
| Google | Google ログイン、Google Drive のバックアップ・復元 |
| GitHub | レポート用テンプレートの取得（匿名）。Issue は**ブラウザーで**作成します |
| Zenn | タグ生成のためのタグ一覧の参照 |

- 本アプリは **GitHub のトークンを持ちません**。レポートの本文を本アプリが送信することはなく、
  ブラウザーで開いた GitHub の Issue 作成画面から利用者自身が投稿します。
- アクセス解析・広告・利用状況の送信はありません。
- 設定画面の「サンプルモード」では、ネットワークに一切出ません。

## 7. 保存期間と削除

| 対象 | 削除方法 |
|---|---|
| ストアのセッション | 「ログアウト」で削除。未ログアウトでも 7 日で失効 |
| Google の認証トークン | 「ログアウト」で OS の資格情報ストアから削除 |
| 端末内のすべてのデータ | 設定 →「全データ削除」（復元不可） |
| Google Drive のバックアップ | 設定から Drive 上のコピーを削除するか、Google ドライブから削除 |
| アンインストール後の残存 | OS の資格情報ストアの項目と Google Drive の `ligrol/` フォルダは手動で削除してください |
